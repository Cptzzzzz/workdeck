# 双模式工作区开发进度

完整目标以 [技术方案](workspace-design.md) 为准：保留现有终端模式，新增可编辑文件工作区，包含管理弹窗、文件读写与预览、自动刷新、WebSocket 和 WebRTC、保存恢复及最终部署。

当前处于开发阶段，尚未部署新功能。阶段成果不会缩小最终交付范围。

## 已完成的基础工作

- 从 `main.tsx` 提取终端视图、管理表单、公共类型和 API 请求层。当前布局与功能继续使用原有组件行为。
- 新增独立的 `internal/files` 包，未接入生产节点，不包含终端终止或 systemd 管理能力。
- 文件引擎保存工作区目录身份，使用受目录边界限制的文件访问，支持有界目录读取、文件属性与分段读取。
- 小文本使用有界快照和内容摘要，避免只根据粗粒度时间戳判断版本，或在旧版本读取中混入新内容。
- 保存支持临时文件、内容校验、版本冲突、节点持久操作记录、重复块确认、上传续传、原子替换和确认丢失后的结果核对。
- 覆盖保存期间的普通权限保留、新建禁止覆盖、硬链接和特殊属性保护，以及有界的私有旧版本副本。
- 节点侧工作区目录切换支持准备、确认、中止和重启后查询；旧目录仍有活动读操作或未完成保存时不会强行切换。
- 新增独立文件工作进程及有界私有 RPC，支持工作区、分页目录、读取和保存；Agent 工作进程池按终端记录中的系统账户启动，关闭时只清理自身进程组。工作区控制请求和基础文件中转已接入 Agent 与 Hub。
- Hub 新增工作区持久记录和根目录切换状态：先记录操作标识和目标，再记录节点确认的候选目录，只有节点确认提交后才发布新修订；节点上线时后台恢复未确认的初始化或目录切换，重试查询或继续原操作。
- 已接入文件 WebSocket 中转、登录绑定的一次性票据、节点签名、工作区修订检查及断连撤权；浏览器文件客户端可列目录、分块读取和保存，保存中断时保留原操作标识供查询和续传。
- 文件连接已支持独立 WebRTC 控制和数据通道：默认先连接中转，比较延迟和稳定性后在请求边界切换；直连异常时重新连接并优先使用中转，未确认的写入仍需按原操作标识核对。界面显示实际链路、两条链路的探测延迟及文件数据速率；授权仍依赖中转连接。跨网络、长时间负载和自适应速率等完整验收仍待完成。
- 浏览器 IndexedDB 草稿存储支持保存编辑基准、当前内容及待确认操作；使用版本令牌阻止多个标签页静默覆盖，已接入基础编辑流程。
- 初步双模式界面已接入真实文件服务：保留原终端视图，提供可刷新的文件树、Monaco 文本编辑、分栏拖动、草稿保存和待确认操作续传；终端宿主在模式切换时保持挂载。完整预览交互仍待实现。
- 工作区左下角增加会话、节点、账户和设置四个管理弹窗：可查找和切换会话，查看节点状态，并复用新建、重命名、终止确认、接入和修改密码表单；字号设置即时生效。子表单支持返回管理弹窗，弹窗支持 Escape、焦点约束及关闭后恢复焦点。
- 自动保存默认关闭，可在当前浏览器的设置中开启；停止输入 1.5 秒后复用手动保存的版本校验和操作记录。冲突、断线、未确认结果、草稿持久化失败或不可安全保存的文件会暂停自动保存；无待确认操作的离线草稿在重新连接后可继续保存。
- 手动刷新、可见时定期核对和页面重新可见时，会同时检查当前文件版本：干净的文本读取新内容并保持编辑器视图；有修改的草稿遇到外部变化时保留并提示冲突，文件无法访问时也保留本地内容。节点侧文件监听和完整的冲突比较处理仍待实现。
- 工作区重新连接后列出本地未保存草稿；即使文件在浏览器关闭前消失且尚未被检测到，也可打开草稿并另存到新路径。已标记为不可访问的草稿不会自动绑定后来出现的同名文件；相关重命名和删除需要先处理草稿。待确认保存可按原操作标识查询，未提交的操作可以取消；已提交的操作需核对当前文件版本后才能解除冲突。节点无记录或仍无法确认时保留原操作和草稿供人工核对。
- 已新增 Markdown 编辑、渲染与并排视图，以及图片和 PDF 预览；Markdown 本地资源和 PDF 范围读取均使用文件连接，PDF 字体与字符映射资源随站点提供。图片与 PDF 预览有大小和解码限制。
- 文件树已支持新建空文件和文件夹；创建记录先保存在浏览器，再使用节点操作日志和原操作标识核对结果，目标已存在时不覆盖。创建文件夹在异常中断或极少数竞争失败时可能遗留隐藏暂存目录，自动清理尚待完成。
- 文件树已接入文件上传和下载：上传前持久化操作标识与内容摘要，断线后可核对结果、重新选择原文件续传或取消；传输中可取消，并在节点确认前保留待核对记录。支持保存接口的浏览器分块写入下载文件。当前上传上限为 1 GiB，非流式保存浏览器暂只支持 20 MiB 内的下载，大文件兼容下载和不可查询结果的人工处理仍待完成。
- 文件重命名已接入文件树和站内表单：目前限定同目录、校验源版本且不覆盖目标，记录操作标识并支持断线后的结果核对。Agent 内不同账户工作进程的最终文件修改和恢复已串行协调；浏览器迁移草稿和打开的标签，迁移冲突会保留记录并提示处理。极端并发、异常结果的人工处理与跨设备草稿体验仍需完善。
- 文件删除已接入站内确认界面：先持久化有界清单，再显式确认并分批处理；结果按项记录，新增内容、对象替换、暂存冲突及结果不明时保留并报告。已删除文件的草稿可重新打开、导出或另存到新文件，旧草稿不会自动覆盖同名新文件。Linux 挂载身份不可核对时拒绝删除。完成或取消的详情保留至少七天，未决记录不会自动清理；极端故障和多设备场景仍需完整验收。
- 建立独立文件数据协议的 JSON 信封和二进制分块编码，限制帧大小、方向、偏移和代次；工作进程请求支持取消及完成屏障。

- 管理表单提取后，四项隔离浏览器回归通过：重命名与终止确认、真实目录选择、持久登录、多设备只读和接管。
- 文件引擎十一项测试通过，使用竞态检测；另有提交前后两类中断恢复子场景。
- 根目录切换、文件工作进程协议和 Agent 工作进程池通过竞态测试；隔离 tmux 会话在工作进程关闭后仍在运行。
- 在临时 root 容器中验证旧普通账户的工作进程不能读取 root 专有文件；该测试不使用生产账户和终端。
- Hub 工作区存储的并发初始化、重启后恢复待切换状态和候选身份核对通过竞态测试。
- 已用隔离的真实 Hub、Agent、工作进程和独立终端验证初始化、目录切换和服务重启恢复；测试终端在重启前后保持同一 pane PID，测试结束后单独关闭。
- Hub 接口的 CSRF、旧修订拒绝，以及初始化和目录切换确认丢失后的手动或后台恢复通过隔离测试。
- 文件协议控制帧和分块边界通过竞态测试；分块解码经过模糊测试，覆盖无效长度、方向、代次和偏移。
- 真实隔离 Hub、Agent 和工作进程的文件中转验证覆盖目录读取、分块下载、保存、票据重放拒绝、退出登录撤权、打开文件时切换目录及未完成保存的恢复；隔离终端进程保持不变。
- 工作进程取消测试验证受阻的目录切换在取消确认后不会延迟执行；关闭浏览器不会关闭终端。
- 浏览器文件客户端在隔离节点的多块读写和提交消息丢失后续传测试通过；真实 IndexedDB 多标签页冲突、待确认操作恢复和异常分块响应测试通过。
- 隔离浏览器验证了模式切换、同一终端宿主和 pane PID、文本编辑保存、拖动分栏、刷新恢复草稿以及保存期间继续编辑；原终端布局和管理表单回归通过。
- 隔离浏览器验证了 Markdown 实时预览、工作区内相对链接、本地图片、外链和越界资源屏蔽、SVG 与脚本隔离、图片资源释放，以及 PDF 分页和范围读取；预览未请求外部资源或通过普通 HTTP 请求节点文件。
- 隔离浏览器和节点测试验证了新建文件与文件夹、不覆盖已有目标、确认丢失后的原操作核对、旧草稿数据库升级、目录身份变化和中断恢复。

## 继续开发的检查顺序

继续开发前检查工作树、隔离实例和操作日志的实际状态，不重复登记节点或覆盖已有密码。阶段测试优先使用独立文件引擎和专用终端；生产终端仅用于只读状态与 PID 保护检查。

后续先完成文件工作进程、工作区身份和协议接入，再把文件客户端接入双模式布局与编辑器；现有终端链路独立保留。最终验收必须逐条覆盖技术方案的产品行为、故障窗口和部署约束，不能以核心包测试代替完整功能验收。
